# نظام إدارة المبيعات وعروض الأسعار وأوامر التشغيل لمصنع الستائر
### متوافق 100% مع وثيقة التوصيف الفني ومواصفات أودو (Odoo 17/18)

تطبيق ويب متكامل مصمم خصيصاً لمصانع ومتاجر الستائر، يحول الدورة الورقية ومحادثات الواتساب إلى نظام رقمي ذكي يملأ البيانات تلقائياً، ويحتوي على محرك حسابات دقيق، ويوفر واجهات REST APIs جاهزة للربط مع Odoo.

---

## 🌟 الميزات المنفذة في النظام

1. **شاشة لقاء العميل السريعة (مرحلتان مريحتان للموبايل):**
   - **المرحلة 1: التسعير والأمتار المباشرة:** إدخال المقاسات (العرض والارتفاع وميل الارتفاع)، واختيار طبقات القماش (حتى 5 طبقات) مع حساب فوري لعدد العروض وأمتار القماش وسعر المتر والتفصيل.
   - **المرحلة 2: تفاصيل التشغيل:** نوع فتح الشباك، مواصفات السقف، لوحة رسم توضيحي بالماوس/القلم (Canvas) لرسم شكل الموديل، وملاحظات المكتب الفني.
2. **محرك الحسابات الذكي (Section 8 & Section 14):**
   - مطبق بدقة مع كافة اختبارات القبول: تقريب لأقرب ربع متر `q25`، حساب أمتار ويفي وعادي ومفرود لكل عروض الرول (عريض، عرض، قلب ط).
   - التوليد التلقائي للإكسسوارات (ريل ويفي، ريل عادي، مواسير، نهايات، طبة، كوابيل مفردة/مزدوجة، كانات، خشب، مسامير عصفورة، شماعات).
   - إرشادات كفاية عمق وارتفاع بيت الستارة وحكم الكفاية (كاف ✓ / ضيق ⚠ / لا يكفي ❌) ورؤية شريط الستارة.
3. **أمر التشغيل المطبوع A4 (تطابق 100% مع الورقة المرفوعة):**
   - نموذج A4 جاهز للطباعة مباشرة دون أسعار، مخصص لفريق المصنع والتركيبات متضمناً الرسم التوضيحي، جدول القماش، جدول الإكسسوارات، والبلتكالة، وملاحظات الفني، وتوقيعات البائع والعميل ومدير التشغيل.
4. **عرض السعر المعتمد (Quotation):**
   - مستند تسعير رسمي مفصل بالغرف، البنود، الخدمات، الخصومات الإضافية، دفعة المقدم، والمتبقي.
5. **متابعة الفرص والمبيعات (CRM & لوحة مهام اليوم):**
   - مسار كانبان يتابع الفرصة عبر مراحلها التسع.
   - رصد المهام المتأخرة، مهام اليوم، الفرص بدون موعد متابعة، وفرص بانتظار الفيد باك.
6. **واجهات الربط والتكامل مع Odoo (APIs & Payloads):**
   - حمولات JSON جاهزة للحقن في موديلات أودو (`curtain.job`, `curtain.room`, `curtain.layer`, `sale.order`).
   - سكريبت بايثون جاهز `odoo_connector_example.py` للربط عبر XML-RPC.
   - تصدير واستيراد البيانات بتنسيق JSON المعياري (القسم 13).

## 📡 أهم واجهات البرمجة (REST APIs)

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/v1/health` | فحص عمل الخادم وقاعدة البيانات |
| `POST` | `/api/v1/calculate` | حساب فوري للأمتار والإكسسوارات وتكلفة الغرفة |
| `GET / POST` | `/api/v1/customers` | إدارة العملاء مع كشف التكرار برقم الهاتف |
| `GET / POST` | `/api/v1/jobs` | قراءة وحفظ أوامر التشغيل |
| `GET` | `/api/v1/jobs/:id` | جلب أمر تشغيل محدد بكامل تفاصيله ورسمه |
| `GET` | `/api/v1/odoo/payload/job/:id` | تجهيز كائن Odoo لموديل `curtain.job` |
| `GET` | `/api/v1/odoo/payload/sale-order/:id` | تجهيز كائن Odoo لموديل `sale.order` |
| `GET` | `/api/v1/today-tasks` | لوحة مهام المبيعات اليومية |
| `GET` | `/api/v1/backup/json` | تصدير كامل البيانات بتنسيق JSON |
